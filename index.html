About Falcon

Falcon is built on public Kaggle datasets covering Finance, Internet, and Retail domains. The benchmark distinguishes itself by pairing each domain with question sets of incremental difficulty levels, allowing for a fine-grained measurement of model capabilities.

The current release includes 500 Chinese questions derived from Kaggle datasets. Future updates will include questions focusing on fuzzy linguistic expressions and real-world production scenarios from Ant Group.

📂 Data & Repository Structure

The Falcon benchmark is divided into two main splits: a Development Set (200 questions) and a Test Set (300 questions). The repository structure is designed for easy integration with evaluation pipelines.

Repository Layout

FALCON/
├── dev_data/                # Development Set (200 Samples)
│   ├── dev.json             # Questions, SQL & Answers
│   ├── tables.json          # Schema information
│   └── db/                  # Database files (SQLite/CSV)
│
└── test_data/               # Test Set (300 Samples)
    ├── test.json            # Questions ONLY (No SQL/Answer)
    ├── tables.json          # Schema information
    └── db/                  # Database files

Core File Formats

dev.json (in dev_data/)

{
  "question_id": "1",
  "question": "What is the average age...?",
  "sql": "SELECT avg(age) FROM ...",
  "answer": [...],
  "dataset_id": "1"
}

test.json (in test_data/)

{
  "question_id": "201",
  "question": "Show the total sales...",
  "dataset_id": "10"
  // Note: No 'sql' or 'answer' fields
}

Key Challenges

SQL-Computational Difficulties

Designed to test complex logic including:

  • Multi-table joins
  • Nested CTEs (Common Table Expressions)
  • Window functions & Ranking
  • Type casting & Regular-expression filters

Linguistic Difficulties

Focuses on natural language ambiguity:

  • Chinese fuzzy time expressions
  • Colloquial business jargon
  • Ellipsis (omitted information)
  • Multi-intent questions

🛠 Submission Helper

For users using DB-GPT for testset execution, we provide a helper script submission/submission_format.py. This script converts your execution result Excel file into the required submission.zip format containing result_sql and result_csv folders.

submission/submission_format.py 
if __name__ == "__main__":
    # Input file name - excel
    INPUT_FILE = "execute.xlsx" # REPLACE WITH ACTUAL EXECEL FILE NAME
    # Output file name - zip
    OUTPUT_ZIP = "submission.zip"
